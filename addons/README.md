# Optional add-ons

The only supplied optional integration is the [Home-button helper](../docs/HOME_BUTTON.md), built into this app and off until explicitly enabled. No third-party helper APK, service on your computer, DNS modification, rooted startup script or debloating bundle is included.

Future add-ons should have a clear opt-in, minimal permissions, exact device compatibility and a documented undo. Review compatibility before installing any third-party add-on.
